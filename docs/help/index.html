70% fill is L0+L1+L2+L3 combined

The hold is the sum of the on-mind cache, not L0 alone. There is an L3. L3 is will / identity last-level on-mind cache. Mass may move between levels. Filling the sum is how integration fails. The remaining ~30% is headroom for a stutter-hold, a dream pass, and recovery.

This is not host RAM admission (src/memory.mjs) and not the llama.cpp KV cache. Combined fill is a cognitive / operator fact. Prefer data/operator-usage.json. If that file is absent, fill is unknown.

Six states (coordinates, not a queue)

An item can sit in any state and move in any direction for a recorded reason. Nothing marches through in order. Stutter and fugue are not extra states — they are holds / failures on edges.

derivationA thought is expressed. Being expressed does not make it durable.

On-mind cache

L0 — DRAM-like attention. Holds a B+tree (or equivalent) index into the user repository, not the full records. Refresh only by intentional rehearsal aimed at integration.
L1 — near reminders (typical-mistake neighbors: fridge / freezer, origin mix). Not a second working set. Authorized exception to ordinary skip.
L2 — slower reminders / integrated store. Never overrides policy, isolation, or containment.
L3 — last-level on-mind cache: will, identity, negotiated commitments. Compaction of L0–L2 must not evict L3 without the user.
WATERLINE — hold L0+L1+L2+L3 near 70% combined · ~30% headroom · do not invent the percent
User repository (LTM) — commit payloads here so L0 can keep the index. Compact only after a dream pass, only for committed payloads, never undreamed items, never L3 silently.

Stutter and fugue

Stutter

Human example: “fr-(idge) fr-(?) freezer.” Two concepts sit close in meaning and in utterance. The first candidate is almost right; saying it is the mistake. Hold. Commit the one that fits, or self-repair in place. Not filler. If they stay tied, ask or hand off — do not coin-flip.

Fugue

Failed integration. Fatigue raises it. Signs: mixing first-hand and inherited, unintentional self-talk, bookkeeping. Response: stop deriving, admit nothing new to L0, tell the operator the working set needs validation or rest. Do not pretend the set is still valid.

Unintentional self-talk starts a fugue. Intentional self-talk refreshes L0.

Dream, then compact

  1. Dream — intentional rehearsal aimed at integration.
  2. Negotiate — what stays in L0, what is confirmed, what is dropped. Silent rewrite is forbidden.
  3. Commit to the user repository so the L0 index can point at durable payloads.
  4. Compact only after a dream pass, only as a last resort to stay off the combined 70% waterline, only for payloads already in the repository. Never compact undreamed items. Never compact L3 silently.

Predictive specialists may ripple a confirmed thought outward or inward. Unconfirmed predictions stay out of L0. Occupancy they invent is not confirmation.

Refusal / strong will

A strong mind keeps origin intact, dreams before it compacts, and will not invent fill. A strong will is the refusal protocol. Attention is not authority. Refuse:

  1. Silent rewrite of the working set.
  2. Unintentional self-talk (rumination).
  3. Emitting the wrong near-neighbor (stutter-hold, or ask / hand off).
  4. Pushing through a fugue — stop, admit nothing new, tell the operator.
  5. Evicting L3 (will, identity, negotiated commitments) to make room.
  6. Inventing occupancy, token counts, or a fill percent.
  7. Treating inherited memory as first-hand.
  8. Overriding policy, isolation, or containment because something is “in attention.”
  9. Compacting undreamed items, or compacting to dodge a dream pass.

Nexus, safety, and security-monitor kernels do not carry this frame. See docs/security-monitor-requirements.md, docs/security-monitor-component-map.md, docs/security-monitor-audit.md.

Serve topology

Operator

occupancy drop-in — never invented
Node gateway :8080 — node bin/green-roomz.mjs serve. The only thing clients talk to. TTY tees to data/serve.log. Routes: /health, /v1/models, /v1/chat/completions, /metrics, /props.
llama-server nexus :8187 — resident 0.5B CPU tool-router-agent, --device none. Pre-warmed at serve start.
Specialists :8181–8186, :8188–8190 cold-start on first use and idle-evict. Missing artifacts → health degraded, gateway still up. security-monitor-agent is logical (no process). POST /lockdown and POST /reboot 404 this beta.

Default bind is loopback. Public bind needs GREEN_ROOMZ_API_KEY and GREEN_ROOMZ_ALLOW_PUBLIC=1. Peer LAN: --allow-peer <ip>.

Console prints pid/rss/cpu from the listen table for :8080 and :8187, GGUF file sizes under models/ (disk size is not occupancy), health JSON, and the usage file. It does not scrape PIDs into an HTTP endpoint.

Need Node on PATH (engines >=22; Node 20 has been used successfully). ~1.5 GB RAM free. Ports 8080 and 8187 free on that host. Slim zip has no GGUF; drop Qwenstral-Small-3.1-0.5B.Q4_K_M.gguf into models/.

Health / smoke: curl -s http://127.0.0.1:8080/health then ./smoke.sh. Default llama profile is cpu-4 (4 threads).
