## What is holding

| Area | Status |
|------|--------|
| JSON body | Non-object / array / invalid JSON → 400. `messages` must be array if present. Empty body → `{}`. `Content-Type` must be `application/json` (semicolon charset ok). GET/HEAD with body → 400. |
| Unknown paths | 404 except the `/route` suffix hole above. GET-only routes 405 on POST. |
| Slash map | Allowlisted tokens only; `/forget` 400; `/vision`/`/audio` without parts 400; fences with matching \`\`\` do not switch; native missing → 503 on completions. |

| First JSON (output) | First object only; `route` must be a registry alias; vision/audio without parts rejected; monitor omitted from AVAILABLE. |
| Public bind (happy path) | MVP manifest + `WINDOWS-MVP.md` stay on `127.0.0.1`. `0.0.0.0` without `GREEN_ROOMZ_ALLOW_PUBLIC=1` throws. |
| Lockdown / reboot | Not HTTP-callable. 8080/`green-roomz`/`sad`/`worker`/`logger` denied. Respond/IPC: reject envelope, `executed/spawned/implemented` false. Isolate/network(machine): throw `complex-last`. `lockdown(eth0)` / `secure_reboot(all-nics)` on network: reject, spies not invoked. |

## Not patched

Changing `bindAddress` error text to `/Public\/non-loopback/` would green one test without fixing aliases (`''`, `::0`). Changing IPC to `throw` would green ipc/api tests but fights “reject envelope, not no-op.” USER-fence CR/LS needs a real split + tests, not a one-liner already covered.

## Suggested next (for other roles)

1. Fence USER with the same line-break set as `stripControls` (CR, U+2028, U+2029) and add a `buildNexusPrompt` test.
2. Replace `endsWith('/route')` with an explicit `/v1/chat/completions/route` (and only that) in `EXPLICIT_ROUTES`.
3. Point `test/gateway.test.mjs` public-bind assertion at the real message; treat `''` / `::0` as bind-all.
4. Point ipc/api stub tests at reject envelopes (`ok:false`, `executed:false`) instead of `complex-last` throws — keep fail-loud, never `return` undefined.
